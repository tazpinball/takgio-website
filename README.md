# TAKGIO Website

Static website for [takgio.com](https://takgio.com).

## How to update

1. Edit the HTML/CSS/JS files and bump `version.json` (see `CLAUDE.md`)
2. Commit and push to the `master` branch
3. Vercel auto-deploys within seconds

`CLAUDE.md` holds the project rules and the folder structure; `HANDOFF.md` holds the current state.
